# Exploración: Portafolio a Embudo de Ventas (Sales Funnel)

## 1. Estado Actual
Actualmente, el proyecto web en `src/components/pages/portfolio.tsx` y su configuración de copys en `src/config/i18n.ts` están estructurados como un **Curriculum Vitae interactivo**.

* **Posicionamiento:** "Fullstack Engineer disponible para trabajar".
* **Llamados a la Acción (CTAs):** "Descargar CV" y "Hablemos".
* **Métricas Destacadas:** Años de experiencia, Productos lanzados.
* **Proyectos:** Enfocados en la tecnología ("App construida en...", "REST API con...").

## 2. El Problema (Diagnóstico del Arquitecto)
Este enfoque atrae a reclutadores o clientes que buscan mano de obra técnica (code-monkeys) compitiendo por precio. 
Entregar un "CV" te posiciona automáticamente como un empleado, no como un consultor o socio estratégico.
Los clientes que pagan bien no compran código, compran horas ahorradas, reducción de fricción y aumento de ventas.

## 3. La Oportunidad (El Embudo)
Tenemos proyectos con un ROI masivo que estamos subcomunicando:
1. **Automatización SAT:** Automatiza facturas y ahorra docenas de horas a contadores.
2. **AgentForge:** Plataforma de agentes autónomos para equipos de operaciones.
3. **Bolddy / ConnectLife:** Arquitectura móvil compleja con pagos y tiempo real.

Podemos transformar el portafolio en una máquina de adquisición reestructurando los copys y los CTAs para que el usuario perciba a un **Arquitecto de Soluciones y Automatización IA**, y el único camino lógico sea agendar una llamada de descubrimiento.
